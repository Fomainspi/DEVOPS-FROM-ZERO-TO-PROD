1. Read Sections 1–9.
2. Open a Linux terminal.
3. Complete the command practice in Sections 10–18.
4. Run the safe lab setup script.
5. Complete the troubleshooting mini-lab.
6. Complete the Day 1 practice challenge without looking at the answer key.
7. Complete the 40-question knowledge check.
8. Use the command cheat sheet for revision.
9. Move to Day 2 only when the completion checklist is satisfied.

## Lab safety

The setup script creates files only under your home directory:

    ~/devops-day1/devops-lab

It does not modify system configuration, install packages, delete existing directories, or require sudo.
