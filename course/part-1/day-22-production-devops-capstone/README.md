# Day 22 — Production DevOps Capstone

Build one end-to-end project that integrates Git, Python, Docker, CI/CD, Terraform, AWS, Kubernetes, Helm, security and observability.

## Recommended approach

Build locally first. Prove the application, container and Kubernetes deployment before connecting paid AWS infrastructure.

## Acceptance criteria

- automated tests
- versioned container image
- CI pipeline
- security checks
- Terraform plan/review
- Helm deployment
- RBAC
- probes
- Service and Ingress/TLS where required
- rollback test
- troubleshooting runbook
- cost and cleanup plan
