## Course vision

**DEVOPS FROM ZERO TO PRODUCTION** is a practical learning path designed to take a beginner from foundational concepts to production-oriented DevOps engineering.

The course is built around one principle:

> **Understand the concept → execute it → troubleshoot it → automate it → apply it to production.**

The repository contains lessons, hands-on labs, troubleshooting scenarios, knowledge checks, and reference material.

## Learning philosophy

This is not a command memorization course.

Every technology is introduced through:

1. **Why it matters**
2. **What it is**
3. **How it works**
4. **How to use it**
5. **How to troubleshoot it**
6. **How it appears in production**

## Day 3

## Suggested lab environment

Recommended options:

- Ubuntu 24.04 LTS or another current Ubuntu LTS release
- WSL2 on Windows
- A disposable Linux virtual machine
- A cloud Linux VM

For destructive commands, always use a disposable lab directory or VM.
